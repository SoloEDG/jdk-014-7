# PANEL

安装：`npm install`

本地启动：`npm run dev`

生产构建：`npm run typecheck && npm run build`

测试：`npm run test`

Docker 启动：`docker compose up --build`，访问 http://localhost:3014。

## 批注审阅

在阅读器工具栏点击「圈选批注」，在画面上拖出区域即可创建讨论。批注同时保存：

- **画面区域**：以页面归一化坐标（0–1）记录，与缩放、平移以及「整页 / 逐格」视图无关，切换视图不会漂移。
- **分镜语境**：章节、页码、分镜序号、说话人与当格对白，作为创建时的快照保存。

讨论支持在原位置回复、标记解决、重新打开。讨论列表中的「解决」与「重新打开」都以带时间戳的状态事件记录。

### 作者重裁分镜之后

「重裁分镜」可以模拟作者修改分镜矩形。相关批注会被标记为「待重定位」，画布上以虚线保留**原圈选**；点击「重新定位」再拖一个新范围，旧圈选会作为证据保留在 `originalAnchor` 与修订记录里，不会被覆盖。

### 离线交换

右侧「离线交换」区域可以导出 `.panel-review.json` 审阅包，发给作者或其他审阅者后，对方在「合并审阅包」里导入：

- 合并以**事件**为单位，不按“最后保存时间”整体覆盖：回复与定位修订按 id 去重后取并集，离线回复不会丢；相同批注（内容一致、id 不同）只保留一条。
- 讨论状态由带时间戳的状态事件决定。旧文件里的「未解决」不会覆盖本地较新的「已解决」；较新的「重新打开」仍然生效。
- 可设置交换文件上限（64 KB – 8 MB）。超限时按时间**从旧到新**截断回复、修订与历史状态；每条讨论的正文、原圈选、当前定位与最新状态始终保留，并在导出报告的 `notes` 中说明省略了哪些内容与时间范围，导入方也会看到对应提示。
- 本地已有的内容不会因为导入一个被截断的包而减少。

### 批注跳转与续读点

点击批注（或分镜导航里的批注角标）只会进入「批注预览」：画面移动到批注位置，但**正式续读点**、阅读进度与自动保存的位置都不变。点击横幅上的「回到续读点」即可恢复。新建批注不会打断当前阅读位置。

### 已知取舍

- 交换包截断以“新事件优先”，因此对方的旧回复可能缺席，需要时可让其重新导出更小范围的包。
- 批注与阅读进度保存在浏览器 `localStorage`；清理站点数据会丢失，请及时导出审阅包。
